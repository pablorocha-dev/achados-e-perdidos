# Achados e Perdidos — IFPA

Sistema web (com suporte futuro a aplicativo mobile) para cadastro, busca e gerenciamento de itens achados e perdidos.

## Tecnologias Utilizadas

* **Backend:** Java, Spring Boot, Maven, PostgreSQL
* **Frontend:** Dart, Flutter (Web / Mobile)
